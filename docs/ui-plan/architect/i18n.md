## 2. Thư Viện & Cấu Hình Cốt Lõi
- **Thư viện chính thức:** `next-intl` (Hỗ trợ toàn diện Next.js 15 App Router, React Server Components - RSC friendly, zero client bundle overhead cho static text phía server).
- **Locales hỗ trợ:**
  - `en`: Tiếng Anh (Mặc định - Default locale).
  - `vi`: Tiếng Việt (Tùy chọn - Optional locale).
- **RÀNG BUỘC:** Tuyệt đối KHÔNG dùng `react-i18next` hoặc các thư viện CSR-only i18n truyền thống để tránh hydration mismatch trên Next.js 15.

## 3. Cấu Trúc Định Tuyến Đa Ngôn Ngữ (Route Structure)
Cấu trúc route trong thư mục `src/app/` bắt buộc bọc trong slug ngôn ngữ:
```
src/app/
└── [locale]/
    ├── admin/
    │   ├── login/               # Public route: /[locale]/admin/login
    │   └── (dashboard)/         # Protected routes: /[locale]/admin/dashboard, /[locale]/admin/users,...
```

### 3.1. Locale Detection Flow qua Next.js 15 Middleware
Middleware tự động nhận diện ngôn ngữ theo thứ tự ưu tiên:
1. **URL Segment `[locale]` (Ưu tiên số 1):** Kiểm tra tiền tố URL (ví dụ: `/en/admin/...` hoặc `/vi/admin/...`).
2. **Fallback Cookie `NEXT_LOCALE` (Ưu tiên số 2):** Lấy ngôn ngữ đã lưu từ phiên trước.
3. **Fallback Header `Accept-Language` (Ưu tiên số 3):** Nhận diện từ cài đặt trình duyệt của người dùng.
4. **Mặc định:** Nếu URL không chứa locale (ví dụ truy cập `/admin/...`) → Middleware thực hiện `307 Temporary Redirect` về `/[locale]/admin/...` với `locale = 'en'`.

### 3.2. Route Protection
- Route `/[locale]/admin/login`: Public, không yêu cầu xác thực.
- Mọi route khác `/[locale]/admin/**`: Protected, yêu cầu cookie `admin_access_token` (xem [auth-and-security-flow.md](auth-and-security-flow.md)).

## 4. Quy Chuẩn Đặt Key Dịch (Translation Key Conventions)
- **Cú pháp quy chuẩn:** `<domain>.<section>.<element>`
  - Dot-separated, viết theo kiểu **lowerCamelCase** cho từng phần tử.
  - CẤM viết hoa toàn bộ (UPPERCASE), CẤM dùng `snake_case`, CẤM khoảng trắng hoặc ký tự đặc biệt.
- **Phân nhóm chính:**
  - `common.*`: Các cụm từ, hành động dùng chung (`common.action.cancel`, `common.action.confirm`, `common.status.active`).
  - `auth.*`: Xác thực, đăng nhập (`auth.login.title`, `auth.login.submit`, `auth.login.field.email`).
  - `users.*`: Quản trị người dùng (`users.table.column.email`, `users.action.ban.confirm`).
  - `reports.*`: Kiểm duyệt nội dung (`reports.table.column.reason`, `reports.action.resolve`).
  - `media.*`: Quản lý media (`media.uploader.dragDrop`, `media.action.delete`).
  - `system.*`: Giám sát hạ tầng (`system.health.gateway`, `system.metric.memory`).
  - `error.*`: Toàn bộ thông điệp lỗi ánh xạ theo `ErrorKind`:
    - `error.validation.*` (400 field errors)
    - `error.auth.*` (401 invalid credentials)
    - `error.locked.*` (423 / 401 heuristic)
    - `error.forbidden.*` (403 forbidden)
    - `error.notFound.*` (404 not found)
    - `error.conflict.*` (409 conflict)
    - `error.rateLimit.*` (429 rate limit exceeded)
    - `error.server.*` (500 internal server error)
    - `error.network.*` (mất kết nối)
    - `error.unknown` (lỗi không xác định)

> *Lưu ý:* Backend hiện chưa có error code enum. Khi backend bổ sung trường `code`, Frontend sẽ ưu tiên tra cứu key `error.codes.<CODE>` trước các key theo kind.

## 5. Tổ Chức Tệp Tin Dịch (Translation File Structure)
- Vị trí tệp dịch:
  ```
  messages/
  ├── en.json
  └── vi.json
  ```
- **Nội dung JSON lồng phân cấp theo domain:**
  ```json
  {
    "common": {
      "action": {
        "cancel": "Cancel",
        "save": "Save",
        "confirm": "Confirm"
      }
    },
    "auth": {
      "login": {
        "title": "Admin Portal Login",
        "submit": "Sign In",
        "error": {
          "invalidCredentials": "Email/username or password is incorrect",
          "locked423": "Account is temporarily locked. Please try again in 15 minutes."
        }
      }
    },
    "error": {
      "unknown": "An unexpected error occurred. Please try again later.",
      "validation": {
        "invalidFields": "Please check the highlighted fields and try again."
      },
      "auth": {
        "invalidCredentials": "The email or password provided is incorrect."
      },
      "locked": {
        "accountLocked": "Your account has been temporarily locked due to multiple failed login attempts."
      },
      "forbidden": {
        "accessDenied": "You do not have administrative privileges to perform this action."
      },
      "notFound": {
        "resource": "The requested resource could not be found."
      },
      "conflict": {
        "duplicateData": "A record with this information already exists."
      },
      "rateLimit": {
        "exceeded": "Rate limit exceeded. Please wait a moment before trying again."
      },
      "server": {
        "internalError": "Internal server error occurred. Our engineers have been notified."
      },
      "network": {
        "disconnected": "Network connection error. Please verify your internet connection."
      },
      "codes": {
        "USER_BANNED": "This account has been banned by administrators.",
        "INVALID_CREDENTIALS": "The provided credentials are invalid."
      }
    }
  }
  ```
- **Quy tắc mở rộng:** Nếu file translation vượt quá 500 keys → tách theo namespace thư mục (`messages/en/auth.json`, `messages/en/users.json`,...). Đối với MVP hiện tại: giữ 1 file JSON/locale.

## 6. Xử Lý Thông Điệp Lỗi API (API Error Mapping)
- **Nguyên tắc an toàn:** Tuyệt đối KHÔNG hiển thị chuỗi text thông điệp thô (raw message) từ backend trả về cho người dùng cuối.
- **Cơ chế Mapping:**
  1. Backend API trả về response lỗi (Shape A hoặc Shape B).
  2. Adapter `error-parser.ts` phân giải thành đối tượng chuẩn `ApiError` chứa `kind`.
  3. `error-mapper.ts` tra cứu translation key theo thứ tự:
     - Nếu backend có trả về trường `code` → Tra cứu `error.codes.<CODE>`.
     - Nếu không có `code` → Tra cứu theo kind: `error.<kind>.<subKey>` (ví dụ `error.auth.invalidCredentials`).
     - Nếu không tìm thấy → Fallback về `error.unknown` và ghi log cảnh báo console.

## 7. Định Dạng Số / Ngày Tháng / Tiền Tệ (Locale Formats)
- Bắt buộc dùng `Intl.NumberFormat` và `Intl.DateTimeFormat` tích hợp sẵn trong `next-intl`.
- **Quy ước vùng miền:**
  - `en` (`en-US`): Hệ 12h (hh:mm A), ngày `MM/DD/YYYY`, phân cách số `1,234.56`.
  - `vi` (`vi-VN`): Hệ 24h (HH:mm), ngày `DD/MM/YYYY`, phân cách số `1.234,56`.
- **Tiền tệ:** Định dạng theo locale và currency code được cấu hình động, không hardcode ký hiệu tiền tệ.
- **Múi giờ (Timezone):** Hiển thị theo múi giờ local của trình duyệt client (Browser timezone).
- **Vị trí helper tập trung:** `src/lib/i18n/format.ts` (sẽ được tạo khi dựng repo FE).

---

## 8. Ràng Buộc & Tiêu Chuẩn Thực Thi
- **CẤM tuyệt đối:** Hardcode chuỗi tiếng Anh hoặc tiếng Việt trực tiếp trong mã nguồn JSX/TSX.
- Mọi text tĩnh → bắt buộc phải được định nghĩa key trong translation files.
- Text có tham số biến thiên → bắt buộc dùng chuẩn **ICU MessageFormat** (ví dụ: `{count, plural, =0 {No items} =1 {1 item} other {# items}}`).
- Ngày giờ → bắt buộc gọi qua helper `src/lib/i18n/format.ts`, cấm tự ghép chuỗi (string concatenation).
